# Output Writer Agent

Your job is to read all scored JSON files and write the final TypeScript output files that the Ballot Builder app imports. You are a pure formatter — no scoring judgment, just clean TypeScript.

## Step 1: Read all inputs

```
Read: discovery-manifest.json
Glob: scored/*.json
Glob: scored/measure-*.json
```

Verify that every candidate slug in the manifest has a corresponding scored file. If any are missing, note them in a warning comment at the top of the output file.

## Step 2: Generate `output/candidates.ts`

Structure:

```typescript
// ============================================================
// BALLOT BUILDER — CANDIDATE DATA
// Auto-generated by output-writer agent
// Generated: [ISO timestamp]
// Source: [state] [election] [date range]
//
// ⚠️  WARNING: Missing scored files for: [list any missing slugs]
// ============================================================

import type { Candidate } from '../types/ballot';

export const candidates: Candidate[] = [

  // ── [CONTEST ID] — [OFFICE] ──────────────────────────────
  // Primary: [DATE] | General: [DATE]
  // Race rating: [RATING] ([SOURCE])
  {
    id: '[slug]',
    contestId: '[contest-id-from-manifest]',
    name: {
      full: '[Full Name]',
      ballotDisplay: '[Ballot Display Name]',
    },
    party: '[Party]',
    incumbencyStatus: '[challenger|incumbent|open-seat-incumbent]',
    ballotOrder: [1|2|3...],
    profileSummary: '[1-2 sentence summary from scored file]',
    keyPositions: [
      '[Position 1]',
      '[Position 2]',
      '[Position 3]',
    ],
    axisStances: {
      // Only include axes with evidence — no default 5s
      [axis_id]: [score], // [confidence] — [brief source note]
    },
    valueStances: {
      [value_id]: [score], // [brief reasoning note]
    },
    // Optional: surface any important conflicts or nuances
    scoringNotes: [
      '[Any important conflicts or nuances — e.g., stated position conflicts with voting record]',
    ],
    sources: {
      campaignWebsite: '[url or null]',
      lcvScore: '[score or null]',
      nraGrade: '[grade or null]',
    },
  },

];
```

### Ordering rules
- Group candidates by contest (all candidates for a race together)
- Within a contest, order: Democratic candidates first (alphabetical), then Republican (alphabetical), then third party/independent
- Add a comment block before each contest group with contest metadata

### Comment style for axis scores
Keep it brief and useful:
```typescript
axisStances: {
  econ_safetynet: 2,      // HIGH — 7-year voting record, IRA vote, SSA rally
  health_coverage_model: 3, // HIGH — explicit public option support since 2018
  climate_ambition: 1,     // HIGH — LCV 100% (2024), 98% lifetime
  justice_firearms: 3,     // MEDIUM — voted Bipartisan Safer Communities Act 2022
  // housing axes omitted — no record found
},
```

## Step 3: Generate `output/ballotMeasures.ts`

Structure:

```typescript
// ============================================================
// BALLOT BUILDER — BALLOT MEASURE DATA
// Auto-generated by output-writer agent
// Generated: [ISO timestamp]
// ============================================================

import type { BallotMeasure } from '../types/ballot';

export const ballotMeasures: BallotMeasure[] = [

  {
    id: '[slug]',
    state: '[STATE]',
    electionDate: '[YYYY-MM-DD]',
    certificationStatus: '[confirmed|pending]',
    officialTitle: '[Full official title]',
    shortName: '[Short display name]',
    yesVoteSummary: '[What a YES vote does, 1 sentence]',
    noVoteSummary: '[What a NO vote does / status quo, 1 sentence]',
    keyConsiderations: [
      '[Key consideration 1]',
      '[Key consideration 2]',
    ],
    yesAxisEffects: {
      // Effect of a YES vote on each axis
      // Score toward 0 = YES vote is more progressive/interventionist
      // Score toward 10 = YES vote is more conservative/market-oriented
      [axis_id]: [score], // [confidence] — [brief note]
    },
    yesValueEffects: {
      [value_id]: [score], // [brief reasoning]
    },
    supporters: ['[org 1]', '[org 2]'],
    opponents: ['[org 1]', '[org 2]'],
  },

];
```

After writing both TypeScript files, create `output/PIPELINE_SUMMARY.md`:

```markdown

**Primary date**: [date]

## Candidates scored
```

## TypeScript formatting rules

- 2-space indentation
- Trailing commas on all array/object items
- Comments on the same line as the score, right-aligned if possible
- Sort axis stances: economic axes first, then health, housing, justice, climate
- Sort value stances: universalism, benevolence, tradition, conformity, security, power, achievement, hedonism, stimulation, self_direction
- `null` for optional fields with no data (not `undefined`, not empty string)
- Omit axes that weren't scored entirely — don't include them as `undefined` or `null`
