Option B Refined — Collapsible Banners

Updated per your feedback: "Blueprint" / "Build" naming replaces "Values" / "Vote".
"About You" (demographics) is folded into the Blueprint flow as its first sub-step, not a separate phase.

Key changes from v1:
  • 3 phases instead of 5 — Select Ballot → Blueprint → Build
  • "About You" demographics is now the first part of Blueprint (shown as sub-step text), not its own chip
  • "Blueprint" covers: demographics → assessment → profile review (one continuous flow)
  • "Build" covers: ballot items → summary
  • Retake assessment = re-expand the Blueprint banner (no separate button needed)

Phase Model Summary

Phase Banner Color Sub-steps Chip Label
Select Ballot Green (auto-completes) State → Ballot picker "Austin, TX" (or selected location)
Civic Blueprint Purple (brand) About You → Assessment → Profile Review "Blueprint"
Build Your Ballot Blue Per-item voting → Summary "Build"
How this consolidates overlapping features:
  • "About You" + "Values" + "Profile" → single "Civic Blueprint" phase with 3 sub-steps
  • "Retake" button → tap the Blueprint chip to go back to profile review, where "Redo Assessment" is available
  • "Vote" tab → "Build Your Ballot" phase (construction metaphor matches "Ballot Builder" brand)
  • Summary is a completion state of Build, not its own phase
