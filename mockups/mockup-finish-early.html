How it works:

  1. "Answered enough? See your results now" — appears below the skip button after the hard minimum of 5 questions. Subtle, not pushy. Doesn't compete with the main question UI.
  2. Confirmation interstitial — shows what's covered, what's not, and which domains would benefit most from more answers. Default action is "Keep going" (primary button). Shows remaining count so users know it's not much longer.
  3. Resume prompt — when user returns with a saved session, shows their progress with domain pills (covered vs remaining). Three options: continue, see results now, or start fresh.
  4. Session persistence — after each answer, the hybrid session is saved to localStorage. Survives tab close, refresh, and navigation. Cleared when the assessment is completed.

Design decisions:

  • The "see results" link is deliberately low-prominence — most users should complete the assessment. We don't want to encourage quitting, just provide an escape hatch for those who need it.
  • The interstitial names specific domains that are uncovered, so the user can make an informed decision about whether those topics matter to them.
  • The resume prompt uses "Continue where I left off" as the primary CTA — returning users who saved progress probably want to finish.
  • "See results with what I have" on the resume prompt uses the existing imputation logic to fill gaps from cross-axis correlations.
